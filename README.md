# EVES — Site institutionnel

Portfolio institutionnel et vitrine du projet EVES (Éducation, Vulnérabilités de l’Enfance et de la Jeunesse, Économie Sociale et Solidaire).

## Stack

- Vite + React
- Lucide React
- CSS responsive, sans backend requis pour la vitrine
- Déploiement Vercel-ready

## Lancer en local

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Le projet est configuré pour Vercel avec `vercel.json` et produit le dossier `dist`.

## Contenu

Le contenu de la vitrine reprend le document de projet EVES — Version 16, juillet 2026 : vision, mission, cinq objectifs spécifiques, indicateurs d’impact, approche ESS, pilote dans le Noun et horizon 2027–2029.
